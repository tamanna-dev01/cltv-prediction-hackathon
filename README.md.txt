# Customer Lifetime Value (CLTV) Prediction

## Project Overview

Customer Lifetime Value (CLTV) is an important business metric that estimates the value a customer is expected to generate over their relationship with a business.

This project focuses on predicting Customer Lifetime Value using historical customer transaction data and machine learning techniques.

The objective is to transform customer-level transaction data into meaningful features, build a predictive model, evaluate its performance, and generate CLTV predictions that can support data-driven business decisions.

---

##  Business Problem

Businesses need to understand which customers are likely to generate high future value.

Accurate CLTV prediction can help businesses:

- Identify high-value customers
- Improve customer retention strategies
- Prioritize marketing efforts
- Allocate marketing budgets more effectively
- Develop targeted customer campaigns
- Understand customer purchasing behavior

The goal of this project is to build a machine learning model that can estimate the lifetime value of customers based on historical transaction behavior.

---

##  Project Objectives

The main objectives of this project are:

1. Understand and explore the customer transaction dataset.
2. Perform data cleaning and preprocessing.
3. Conduct exploratory data analysis (EDA).
4. Engineer relevant customer-level features.
5. Prepare the data for machine learning.
6. Train a machine learning model for CLTV prediction.
7. Evaluate model performance using appropriate metrics.
8. Generate customer-level CLTV predictions.
9. Extract meaningful business insights from the analysis.
10. Provide recommendations based on the results.

---

## Dataset

The project uses customer transaction data provided for the CLTV prediction hackathon.

The dataset contains information related to customer purchasing behavior and transaction history.

The original competition dataset is not reproduced here if its distribution is restricted.

### Data characteristics

The analysis considers customer behavior such as:

- Purchase frequency
- Transaction value
- Customer spending
- Recency-related behavior
- Historical purchasing patterns
- Other engineered customer-level features

> **Note:** The exact dataset structure and feature definitions are documented in the analysis notebook.
